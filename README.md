# وكيل العمل على تيليجرام — النسخة الأولى

بوت تيليجرام شخصي يستقبل النصوص وملفات PDF وWord وExcel، ويحللها مع ذاكرة دائمة قابلة للمراجعة والحذف.

## ما يعمل الآن

- استقبال الرسائل وتحليلها.
- استقبال PDF وDOCX وXLSX وTXT وMD وCSV.
- حفظ الملفات والنص المستخرج محليًا.
- حفظ تعليمات دائمة بالأمر `/remember`.
- عرض الذاكرة بالأمر `/memories` وحذف بند بالأمر `/forget`.
- حفظ سياق المحادثة واسترجاع المعرفة السابقة.
- تقييد الوصول إلى أرقام حسابات تيليجرام المسموح بها.
- وضع التحليل والاقتراح فقط، دون تنفيذ أعمال خارجية.

## إنشاء البوت

1. افتح المحادثة الرسمية `@BotFather` في تيليجرام.
2. أرسل `/newbot`.
3. اختر اسمًا للبوت ثم اسم مستخدم ينتهي بكلمة `bot`.
4. احتفظ بالرمز الذي يعطيك إياه BotFather بسرية تامة.

## التشغيل على Windows

1. ثبّت Python 3.11 أو أحدث.
2. افتح PowerShell داخل مجلد المشروع.
3. نفّذ:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

4. افتح ملف `.env` وأضف `TELEGRAM_BOT_TOKEN` و`OPENAI_API_KEY`.
5. شغّل:

```powershell
python app.py
```

6. افتح البوت وأرسل `/myid`.
7. ضع الرقم في `ALLOWED_TELEGRAM_USER_IDS` داخل `.env` ثم أعد تشغيل البوت.

## التشغيل الدائم على Render

يتضمن المشروع ملف `render.yaml` لإنشاء Background Worker مع قرص دائم للذاكرة.
عند النشر أضف القيم السرية التالية داخل Render ولا تضعها في GitHub:

- `TELEGRAM_BOT_TOKEN`
- `OPENAI_API_KEY`
- `ALLOWED_TELEGRAM_USER_IDS`

إعداد القرص الدائم ضروري حتى لا تضيع الذاكرة والملفات عند إعادة تشغيل الخدمة.

## أوامر البوت

- `/start` بدء الاستخدام.
- `/myid` معرفة رقم حسابك.
- `/remember اكتب التعليمات` حفظ تعليمات دائمة.
- `/memories` عرض التعليمات المحفوظة.
- `/forget 3` حذف البند رقم 3.

## الملفات والبيانات

توجد قاعدة الذاكرة داخل `data/agent.db` والملفات داخل `data/files/`. لا تشارك هذا المجلد، ولا ترفعه إلى مستودع عام.

## ضوابط مهمة

- لا ترفع بيانات مرضى معرفة بالاسم أو الهوية أو رقم الملف في النسخة التجريبية.
- لا ترسل رمز Telegram أو مفتاح الذكاء الاصطناعي في المحادثات.
- التشغيل الحالي يستخدم polling ويحتاج أن يبقى الجهاز أو الخادم يعملًا.
- ملفات PDF المصورة تحتاج إضافة OCR في مرحلة لاحقة.
- البحث الحالي نصي؛ يمكن ترقيته لاحقًا إلى ذاكرة دلالية وقاعدة بيانات مؤسسية.
